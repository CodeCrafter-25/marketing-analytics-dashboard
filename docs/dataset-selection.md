# Dataset Selection

## Selected Dataset

**Dataset:** Marketing Campaigns & Conversions Dataset  
**Version:** 1.0.0  
**Source:** Analytics Engineering  
**License:** CC BY 4.0  
**Data Period:** 2023-01-01 to 2025-12-31

Source:
https://www.analyticsengineering.com/datasets/marketing-campaigns

## Dataset Description

This synthetic dataset represents the marketing activities of a fictional business.

The data is stored in four related tables:

- `campaigns` — campaign details, channels, objectives, dates, and planned budgets
- `daily_spend` — daily impressions, clicks, and advertising spend
- `leads` — leads attributed to marketing campaigns
- `conversions` — converted leads, conversion types, and attributed revenue

## Why This Dataset Was Selected

The dataset supports an end-to-end marketing analytics project using SQL, BigQuery, and Tableau.

It allows the analysis of:

- Marketing campaign and channel performance
- Advertising spend and budget utilization
- Impressions and clicks
- Lead generation
- Conversion performance
- Attributed revenue
- Customer acquisition efficiency
- Return on advertising spend

The relational structure also provides an opportunity to demonstrate SQL joins, aggregation, data modelling, validation, and protection against duplicated metrics.

## Planned Calculated Metrics

- Click-Through Rate (CTR)
- Cost per Click (CPC)
- Lead Conversion Rate
- Cost per Lead (CPL)
- Cost per Acquisition (CPA)
- Return on Advertising Spend (ROAS)
- Return on Investment (ROI)
- Budget Utilization Rate
- Revenue per Conversion

## Dataset Limitation

The dataset is synthetic and represents a fictional business. Therefore, the results should not be treated as real industry benchmarks.
